## 0. Big picture / 전체 구조

- One React SPA serves two things: the public **landing page** (`#/`) and a **"AI 운영실" console preview** (`#/app/<route>`), switched by URL hash (`lib/routes.ts:59-66`, `App.tsx:79-83`).
- Two build modes (`main.tsx:16-45`):
  - **preview (default)** — landing + console running purely on in-memory fixtures; no network. Landing HTML is pre-rendered and hydrated when the start view is landing (`main.tsx:29-41`).
  - **live** (`VITE_CONSOLE_MODE === "live"`, deployed at `/app2`) — renders `LiveRoot` (not recovered) which feeds real data into `App` via the `live` prop (`App.tsx:35-41`). Live beta is **read-only**: task creation shows a toast "베타는 조회 전용입니다…" and closes (`App.tsx:192-200`); the quote instant-create path is disabled in live (`App.tsx:435`).
- Everything the console "does" in preview is local state mutation + toast; actual execution (API/로컬 실행기/유료 모델) is explicitly deferred to "Phase 2" in many strings (e.g. `WorkPage.tsx:220`, `App.tsx:230`).

### 2.4 Status lifecycles
- **Task** (observed transitions):
  - create (generic) → `queued`, progress 0, timeline [로컬 초안 생성 complete, 실행 전 점검 current, 실행 upcoming] (`App.tsx:209-233`).
  - create (상수 quote) → directly `done`, 100 %, 3 complete steps, resultSummary set (`App.tsx:265-292`).
  - `waiting_user` (needsConfirmation, cost string) → **confirmTask** → `queued`, progress ≥15, needsConfirmation=false, step `confirm`→complete, step `analyze`→current (`App.tsx:298-327`).
  - `running` → `failed` (disconnected scenario): errorMessage + the `collect` step marked failed, "자동 유료 재시도는 실행하지 않았습니다" (`fixtures.ts:610-626`).
