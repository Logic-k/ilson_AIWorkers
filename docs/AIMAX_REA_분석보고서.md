## 3. 화면 구조 (운영실)

랜딩 SPA 안에 해시 라우트 `#/app/{home|employees|work|connections|help}`로 "AIMAX CONSOLE · REBUILD" 로컬 프리뷰가 들어 있습니다(로그인·결제·API 없음, 메모리 상태만). [관찰]

| 화면 | 구성 |
|---|---|
| 홈 | 오늘의 운영 요약(실행 중 링·확인 필요·최근 완료·연결 문제), 확인 대기 목록, 실행 중 업무, 최근 결과, 자주 쓰는 직원 |
| AI 직원 | 실행 방식 필터(웹 / 웹+로컬 / 로컬 / 외부 앱), 직원 목록 + 상세(받는 정보·만드는 결과·비용 기준·할 수 있는 일·필요한 연결), 입사지원서 |
| 업무 | 상태 탭(전체·확인 필요·실행 중·완료·실패), 업무 상세(진행률, 단계 타임라인, 요청 ID) |
| 연결 및 설정 | AI 모델(Gemini·OpenAI·Claude), 데이터(Pexels·Apify), 실행 환경(로컬 실행기 버전·마지막 연결). "원문 키는 다시 보여주지 않습니다" |
| 도움말 | 오류 보고와 지원 |

실제 콘솔(`/app`)은 "구매자 이메일 + 임시 비밀번호" 로그인 후 같은 개념을 vanilla JS로 구현합니다. [관찰]

## 4. 데이터 모델과 상태

- **업무 상태**: 대기 → 실행 중 → (확인 필요 ↔ 확인) → 완료 | 실패. 실제 콘솔 job 상태는 `queued · generating · ready_for_publish · running · done · failed · cancelled`. [관찰]
- **직원 상태**: 바로 사용 / 설정 필요 / 업무 중 / 사용 불가. [관찰]
- **업무 폼 DSL**: 필드 종류 10가지(text, textarea, number, date, file, select, choice[chips|cards], checkboxGroup, textList, itemTable) + 조건부 표시(`visibleWhen`) + "고급 설정" 접기 + 직원별 예상 비용 계산. [관찰]
- **최근 설정 불러오기**: 칩을 눌렀을 때만 복원, 현재 필드 정의로 검증 후 덮어씀. [관찰]
- **견적서 구성**: 기본 정보 → 항목 → 공급가액·부가세·총액 → 유의사항 → 전달 말씀 → 서명, A4 인쇄. [관찰]
- 원본의 빈틈 [관찰]: `setup_required`여도 업무 생성이 막히지 않음, 숫자 범위·날짜는 검증하지 않음, 일부 직원 폼은 정의만 있고 도달 불가.

## 5. 운영 콘솔 API와 실행 구조

| 영역 | 엔드포인트(요약) | 의미 |
|---|---|---|
| 인증 | `/api/auth/{login,logout,me,change-password}` | 구매자 계정 |
| 작업 | `/api/jobs`, `/{id}/cancel`, `/guard/acknowledge` | 작업 큐, 중단, **반복 오류 가드** |
| 실행기 | `/api/agent/{status,commands}`, `/api/downloads/{agent,tickets,options}`, `/api/version` | PC 실행기 연결·원격 명령·배포 |
| 직원 | `/api/workers` | 직원 카탈로그(권한·실행 방식·이력서) |
| 조사 | `/api/research/{projects,items,discovery,brief,integrations}` | 링크 수집 → Apify SNS 수집 → AI 분석 → 브리프 |
| 세금계산서 | `/api/tax/{settings,invoices,…/preflight,issue,sync}` | 별도 "세무 직원"(현재 목록에서 제외) |
| 사용자 | `/api/user/{secrets,writing-style}` | 키 금고, 글쓰기 문체 |

- **[추론] 아키텍처**: 클라우드 컨트롤 플레인(인증·큐·키 금고) + 로컬 실행기(네이버 계정·브라우저 세션 보유, 큐를 폴링해 SmartEditor 조작) + 얇은 웹 콘솔. 실행기는 `aimax://` 커스텀 프로토콜로 깨우고, 3초 간격으로 상태를 확인합니다.
- **[관찰] 가드**: 같은 오류가 반복되면 서버가 해당 업무 유형을 409 `guard_paused`로 거절, 사용자가 "조치했어요"를 눌러야 재개.
- **[관찰] 유료 호출 안전장치**: 실행 전 비용 확인, `confirm_paid` 플래그, 자동 유료 재시도 없음, 요청 ID로 중복 방지.

## 6. 보안·운영상 관찰 (참고)

- 랜딩 번들의 **소스맵이 공개**되어 원본 TS 소스가 그대로 복원됩니다. [관찰]
- 운영 콘솔 전체 클라이언트 코드가 **비로그인 상태로** 내려옵니다(서버 권한 검사가 있다면 정보 노출 수준). [관찰]
- 운영사 메인 저장소가 공개 상태이며 라이선스가 없습니다(코드 재사용 권리 없음). [관찰, `03_*` 참고] — 본 프로젝트는 이 저장소의 코드를 사용하지 않았습니다.
- 네이버 자동 발행·대량 서로이웃 신청은 플랫폼 약관·스팸 위험이 있습니다. [추론]

## 7. 일손(Tauri)으로 옮긴 것 / 바꾼 것

| AIMAX 방식 | 일손 구현 | 비고 |
|---|---|---|
| 클라우드 콘솔 + PC 실행기 | **단일 데스크톱 앱**(Tauri 2 + Rust). 서버 없음 | 계정·결제 불필요, 데이터는 PC의 SQLite |
| BYOK (Gemini 기본) | BYOK **Claude**(Opus 5.5 기본, Sonnet/Haiku 선택) | 키는 OS 자격 증명 저장소, 마스킹 표시 |
| 비용 확인 후 실행 | 단계 앞 **비용 게이트**: 예상치 + 넉넉한 상한, 자동 승인 한도 설정 | 실패 후 이어하기 시 비용 재확인 |
| 중간에 멈춰도 이어서 | 단계별 **체크포인트**(SQLite), 앱 재시작 시 '멈춤'으로 복구 | 멈추기 버튼은 진행 중 단계도 즉시 중단 |
| 반복 오류 가드 | 같은 직원 2연속 동일 오류 → **점검 필요** + "조치했어요" | 로컬에서 구현 |
| 네이버 자동 발행 | **하지 않음** → "본문 서식 복사"로 편집기에 붙여넣기 | 약관·계정 위험 회피 |
| 서로이웃 대량 신청 | **하지 않음** → 공개 정보 기반 후보 목록 + 맞춤 연락 문구 | 개인정보 수집 금지 원칙 |
| 외부 파트너 링크(자료조사·지원사업) | 앱 안에서 직접: 링크 본문 수집 + Claude 웹 검색으로 출처 붙은 브리프 | |
| 견적서(브라우저 localStorage) | Rust에서 계산·한글 금액 표기, A4 인쇄/PDF, HTML 저장 | 무료 |
| 캡처·OCR 앱 | **파일 정리 직원**으로 대체: 계획 → 확인 → 이동 → 되돌리기 | 삭제 없음, 시스템 폴더 거부 |
| 원본의 빈틈 | 설정 필요 시 생성 차단, 숫자 범위·날짜 서버 검증 | 개선 |

직원 이름·이력서·문구·아바타는 모두 새로 만든 가상 페르소나이며, AIMAX의 코드·이미지·문구를 복사하지 않았습니다.
